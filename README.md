# Image Color Extractor & Computer Vision Analysis

A web-based application built with **Python**, **Streamlit**, **OpenCV**, and **Scikit-Learn** that performs image analysis and extracts dominant color palettes using **K-Means Clustering**.

## Features
- **Image Metadata Extraction:** Displays resolution, format, color mode, and total pixel count automatically.
- **Dominant Color Extraction:** Uses Machine Learning (K-Means) to cluster and extract top 5 dominant colors.
- **Visual Palette Breakdown:** Shows visual color boxes along with their HEX codes and percentage ratios.
- **Interactive Web Interface:** Real-time processing powered by Streamlit.

## Tech Stack
- **Python**
- **Streamlit** (Web Framework)
- **OpenCV & Pillow** (Image Processing)
- **Scikit-Learn** (K-Means Machine Learning)
- **NumPy** (Array & Data Computation)
